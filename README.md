## Dragon-Weather

![Project Banner](https://img.shields.io/badge/Status-Active-brightgreen) ![Tech Stack](https://img.shields.io/badge/Stack-HTML5%20%7C%20TailwindCSS%20%7C%20Chart.js-blue) ![License](https://img.shields.io/badge/License-MIT-yellow)

**Atmosphere Intelligence** is a high-performance, sci-fi/mecha-themed weather command terminal. It combines real-time meteorological data feeds via Open-Meteo with dynamic, aerodynamic wind animations, customizable HUD cards, and stylized anime-inspired graphic elements (such as Akatsuki-styled wind motifs and a mecha-dragon core).

---

## 🚀 Key Features

* **Real-Time Global Telemetry:** Instantly fetches live weather metrics (temperature, humidity, pressure, and wind speed) for any city using the Open-Meteo API.
* **Natural Wind Stream Simulation:** Features dedicated wind-flow container graphics with organic speed shifts, fluid stream lines, and dual-state speed variations.
* **Akatsuki & Mecha Design Language:** Incorporates custom SVG graphics, including a multi-shaded Akatsuki cloud motif referencing dynamic airflow and a rotating mecha-dragon core indicator.
* **Interactive HUD Panel Architecture:** Angled sci-fi card UI elements equipped with hover states, click shockwaves, and dynamic neon lighting effects.
* **Interactive 24-Hour Analytics:** Powered by `Chart.js` to render clean, futuristic temperature trajectory graphs with custom tooltips.

---

## 🛠️ Technology Stack

* **Markup & Style:** HTML5, TailwindCSS (via CDN)
* **Visual Graphics & Icons:** Custom SVG Graphics, Lucide Icons
* **Data Visualization:** Chart.js
* **Data Provider:** Open-Meteo Geocoding & Weather Forecast APIs
* **Typography:** Google Fonts (*Orbitron* for futuristic headers, *Rajdhani* for UI data display)

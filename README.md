# Dragon-Weather

![Status](https://img.shields.io/badge/Status-Active-brightgreen) ![Tech Stack](https://img.shields.io/badge/Stack-HTML5%20%7C%20TailwindCSS%20%7C%20Chart.js-blue)

**Dragon-Weather** is a high-performance, sci-fi/mecha-themed weather command terminal. It merges real-time meteorological data from Open-Meteo with dynamic aerodynamic wind animations, customizable HUD cards, and stylized graphics (including Akatsuki-inspired wind motifs and an animated mecha-dragon core).

## 🚀 Key Features

* **Real-Time Global Telemetry:** Fetches live weather metrics (temperature, humidity, pressure, and wind speed) for any city using the Open-Meteo API.
* **Natural Wind Stream Simulation:** Dedicated wind-flow container graphics with organic speed shifts, fluid stream lines, and hover-triggered high-velocity changes.
* **Anime & Mecha Design Language:** Incorporates custom SVG graphics, featuring a multi-shaded Akatsuki cloud motif referencing dynamic airflow and an interactive mecha-dragon core.
* **Interactive HUD Architecture:** Angled sci-fi card UI equipped with hover states, click shockwaves, and neon lighting effects.
* **24-Hour Thermal Trajectory:** Powered by Chart.js to render clean, futuristic temperature trajectory graphs with custom tooltips.

## 🛠️ Technology Stack

* **Markup & Styling:** HTML5, TailwindCSS (via CDN)
* **Graphics & Icons:** Custom SVGs, Lucide Icons
* **Data Visualization:** Chart.js
* **API Integration:** Open-Meteo Geocoding & Forecast APIs
* **Typography:** Google Fonts (*Orbitron* for headers, *Rajdhani* for UI data display)
